# 2D Elastic Wave Simulation

Two-dimensional, homogeneous isotropic **plane-strain** elasticity on a rectangular grid. Version 0.3 uses scikit-fem Q1 finite elements with a B-bar volumetric projection, positive lumped mass and SciPy sparse algebra. It replaces the unstable displacement-ghost implementation in v0.2.

This is a linear elastic continuum model, not a calibrated material model or a Kirchhoff thin-plate model. x/y displacement components are not a general P/S decomposition.

## Run

Python **3.14** is selected by `.python-version`; your system Python is not changed. Runtime dependencies are NumPy, SciPy, scikit-fem, Matplotlib and Pillow. Metal/MLX is no longer required.

```bash
uv sync --locked
uv run python run.py
uv run python run.py --gif
```

Runtime-only installation: `uv sync --locked --no-dev`. The lockfile records exact versions and hashes. The CPU code and its validation run in CI on Linux, macOS and Windows.

## Develop and verify

`ruff` and `pytest` are in the `dev` dependency group, installed by the default `uv sync`.

```bash
uv run --locked ruff check .
uv run --locked pytest -q
uv run --locked python validation/validate_physics.py
uv lock --check
uv pip check
```

The physics script checks energy conservation, bulk-wave dispersion, Rayleigh-mode convergence and normal free-end reflection against analytical references. It prints JSON. Save execution records under `feedback/`; pytest and Ruff caches already use that directory. Local environments, generated bytecode and agent metadata remain excluded from Git.

See [the validation report](docs/energy-form-validation-2026-10-25.md) for conditions, measured errors, independent review and migration decisions. Passing these cases does not establish a resolution-independent error bound for every configuration.

## Configuration

Edit [SimulationConfig](src/config.py). Construct a new simulation after changing grid, material, damping or time integration; the assembled matrices and implicit factorization are cached for that configuration.

| Default | Value |
|---|---|
| Nodes / spacing | 101 × 20; dx = 0.009901 m, dy = 0.0095 m |
| Node-to-node extent | 0.9901 m × 0.1805 m |
| Young's modulus / Poisson ratio / density | 1000 Pa / 0.25 / 1000 kg/m³ |
| Lamé parameters / bulk speeds | λ = μ = 400 Pa; cp ≈ 1.0954 m/s, cs ≈ 0.6325 m/s |
| Prescribed left-edge x-displacement | 1 mm amplitude, approximately 1.7116 Hz, 10 cycles |
| Boundaries | top/bottom/right naturally traction-free; left edge prescribed |
| Integration / damping | implicit average acceleration / 0.9995 velocity retention |
| Timestep / run duration | approximately 0.812891 ms / 2000 steps ≈ 1.62578 s |

The default source stays active for the whole default run. `source_mode="interior"` instead adds a displacement increment in `source_x_start:source_x_end`; this is not a calibrated body-force input. `input_mode` selects radial or uniform polarization there. The source columns and radial directions use physical coordinates.

`boundary_type` supports `fixed`, `free_top` and `stress_free_all`. `boundary_width` controls fixed strips. A driven left edge replaces the left fixed strip, so the source can reach the interior; other fixed strips remain. Prescribed displacement takes precedence at the driven endpoints. `damping=1` disables damping.

The full admissible material range remains `0 <= poisson_ratio < 0.5`. B-bar mitigates volumetric locking; near incompressibility still demands sufficient resolution and floating-point conditioning. The validation includes ν=0.4999 and does not model the exactly incompressible limit.

## Output

- **p**: x-displacement; **s**: y-displacement; **b**: magnitude.
- Coordinates are metres, with equal geometric aspect and image sample centres aligned to the nodes.
- GIFs render one component at a time using Pillow. Existing filenames remain `p_wave_animation.gif`, `s_wave_animation.gif` and `combined_magnitude.gif`; the first two contain x/y components.
- `gif_num_steps`, `gif_frame_interval`, `gif_frame_rate` and `gif_output_dir` control export, including a final partial interval. Default 10 fps is 100 ms per frame; GIF timing has 10 ms precision.
- Nonfinite states fail explicitly rather than being saved as a valid simulation.

## Numerical method and migration

[Energy, boundary and timestep details](STRESS_FREE_BC_IMPLEMENTATION.md) explain the weak traction condition and the energy estimate. Free boundaries, including corners, require no displacement ghost nodes. The spatial method is second order in the demonstrated smooth-wave cases; both time integrators are second order.

Compared with v0.2, fields are now NumPy float64 arrays with the same `(1, ny, nx, 1)` shape. `ElasticOperator` replaces `FiniteDifferenceOperator`; `WaveSolver.operator` replaces `.fd`. Removed settings are `finite_diff_order`, `implicit_iterations` and `implicit_tolerance`. The implicit system is factorized once and solved directly. Existing glyph/display keys P/S/Both remain aliases for displacement components; the legacy `wave_type` config field does not change the source.

The old [v0.2 audit](docs/code-audit-2026-10-25.md) is historical. Its open stability/accuracy findings are addressed by the v0.3 energy formulation and validation, not by extending the old stencil.
