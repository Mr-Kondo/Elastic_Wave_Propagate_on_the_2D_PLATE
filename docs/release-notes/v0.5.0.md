## 追加

- 比較ケースを利用者が指定できるようにしました。`run_compare.py --case "名前:キー=値,キー=値"`(複数指定可、`--preset` の代わりに使う)。キーは `SimulationConfig` のフィールド名で、値は設定の型に合わせて解釈します。不正な指定は引数エラーになります。
- Colab ノートブックに `CASES` 入力欄(`;` 区切り)を追加しました。

## 改善

- 動画の描画を約3.7倍に高速化(ローカル 53秒→14秒)。毎フレーム再計算していたレイアウトを1回だけ計算して固定しました。見た目は変わりません。
- ffmpeg に libx264 が無い環境では GIF にフォールバックします(v0.4.1 以降の main に含まれる修正)。

## 注意

- ノートブックの既定 `REF` を v0.5.0 に更新しました。
